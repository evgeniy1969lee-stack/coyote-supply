# Coyote Supply

- Делаем кейс №4: прогноз потребности, риски запасов и редактируемый черновик закупки для управляющего кофейней.
- Перед изменениями прочитай `docs/spec.md`, `docs/api-contract.md` и примеры из `docs/fixtures/`. Машиночитаемый контракт — `docs/api-schema.json`. `docs/mvp-plan.md` описывает общий план.
- Frontend владеет `frontend/` и `DESIGN.md`. Backend владеет `backend/`. Формы API и тестовые ответы меняем согласованно в отдельном PR. В UI числа приходят из API или фикстур того же формата.
- Данные демо синтетические. Реальные выгрузки, ключи и рабочие базы держим вне Git. Подключение к Coyote и отправка заказов поставщикам требуют отдельного согласования.
- Работай в своей ветке и в рамках одного этапа. Перед ревью проверь затронутый сценарий, сообщи, что проверено и что осталось. Публикация ветки, PR и слияние идут отдельными действиями.
