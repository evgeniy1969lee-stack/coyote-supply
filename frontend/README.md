# Coyote Supply · Frontend

React, TypeScript и Vite. Тема Tailwind в `src/index.css` использует цвета, радиусы и шрифт из [дизайна](../DESIGN.md). Компоненты shadcn находятся в `src/components/ui/`.

## Запуск

Проверено на Node.js 24.15 и npm 11.12. Команды выполняются из `frontend/`.

```sh
npm ci
npm run dev
```

Откройте адрес, который выведет Vite. На экране «План закупок» можно переключать точки, смотреть прогноз по ингредиенту, править число упаковок и сохранять черновик в браузере. Данные берутся из фикстур контракта в `../docs/fixtures/`, поэтому запускайте фронтенд из полного клона репозитория.

```sh
npm run lint
npm run build
```

Сборка проверяет типы и записывает готовый сайт в `dist/`.
