# Coyote OS · фронтенд

React, TypeScript и Vite. Тема Tailwind в `src/index.css` использует цвета, радиусы и шрифт из [дизайна](../DESIGN.md). Компоненты shadcn находятся в `src/components/ui/`.

## Режим разработки

Сначала запустите FastAPI по инструкции из корневого README. Команды ниже выполняются из `frontend/`. Vite проксирует запросы `/api` в FastAPI. По умолчанию прокси использует порт 8000. Для порта 8090 задайте переменную, как показано ниже. [Запуск FastAPI](../README.md)

```powershell
$env:COYOTE_API_TARGET = 'http://127.0.0.1:8090'
npm ci
npm run dev
```

Откройте адрес, который выведет Vite. Экран «Моя смена» показывает план и предупреждения. В «Закупках» доступны прогноз по ингредиенту и черновик. Copilot отвечает по данным выбранной точки. Прогноз и черновик приходят из API, а сохранённое состояние хранится на сервере.

```sh
npm run lint
npm run build
```

Сборка проверяет типы и записывает сайт в `dist/`. При запуске после сборки FastAPI раздаёт его вместе с API.
